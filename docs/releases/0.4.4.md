# FERPEK Lens 0.4.4

FERPEK Lens 0.4.4 is a small user-interface refinement release focused on the Settings experience.

It is also the first release intended to validate the complete in-app update workflow introduced in 0.4.3.

## Changes

### Settings cleanup

The unfinished Settings placeholders have been removed:

- Server
- Agents
- Detection

These entries did not yet provide any configuration workflow and could appear to be broken navigation items.

The General section now only displays settings that are currently functional.

### Release notes link

The FERPEK Lens update row now displays a **View release notes** link when the release manifest provides a release URL.

This gives administrators direct access to the release information associated with the version reported by the update service.

## Upgrade from 0.4.3

FERPEK Lens 0.4.4 can be installed directly from:

**Settings → Updates**

No database migration or data-volume change is required for this release.

The updater should preserve the existing FERPEK Lens data volume and deployment settings while replacing the Server and Web images with version 0.4.4.
