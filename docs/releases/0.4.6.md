# FERPEK Lens 0.4.6

FERPEK Lens 0.4.6 further refines the in-app update experience.

## Changes

### Update overlay guidance

The global update overlay now makes it explicit that an update continues on the server even if the browser tab is closed.

This reflects the updater architecture: update execution is handled by the host-side FERPEK update service and does not depend on keeping the WebUI open.

## Upgrade from 0.4.5

FERPEK Lens 0.4.6 can be installed directly from Settings → Updates.

No database migration or data-volume change is required for this release.
