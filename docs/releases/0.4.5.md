# FERPEK Lens 0.4.5

FERPEK Lens 0.4.5 improves the in-app update experience.

## Changes

### Global update overlay

FERPEK Lens now displays a global update overlay while a Lens update is in progress.

The overlay:

- blocks interaction with the application while the update is running;
- displays the current update phase;
- remains available independently of the Settings page;
- restores itself after a page reload when the updater still reports an active operation;
- uses the same visual language as the existing FERPEK modal dialogs.

### Automatic reload after update

After a successful FERPEK Lens update, the WebUI automatically reloads so that the newly installed frontend is loaded immediately.

This avoids leaving the previous frontend bundle active in the browser after the Web container has been replaced.

## Upgrade from 0.4.4

FERPEK Lens 0.4.5 can be installed directly from Settings → Updates.

No database migration or data-volume change is required for this release.
