# FERPEK Lens 0.5.0

FERPEK Lens 0.5.0 expands the pack system with a more capable Pack Engine and multi-target source discovery.

## Highlights

- Aggregate Findings can collect context from multiple matching events.
- Aggregate rules can apply conditions to counts and collected values.
- Pack Engine compatibility is now explicitly versioned.
- Agents report their Pack Engine version to the server.
- Pack compatibility can depend on Server, Agent and Pack Engine versions.
- Declarative pack sources can discover multiple files or systemd units.
- Multi-instance services can keep independent runtime source state.
- File source offsets and event identities are isolated per discovered target.
- Findings generated by the Pack Engine focus on describing detected situations rather than prescribing remediation.

## Pack Engine

FERPEK Lens 0.5.0 includes Pack Engine 0.2.0.

The engine adds support for:

- aggregate collections;
- distinct collected values;
- aggregate conditions;
- collection counts in Finding templates;
- stricter rule validation;
- persisted aggregate state;
- explicit Pack Engine compatibility metadata.

## Source discovery

Pack source discovery can now return multiple concrete runtime targets from one logical source.

This enables packs to cover services with multiple instances or log files while keeping one stable logical source identity.

Examples include:

- PostgreSQL clusters with multiple log files;
- wildcard systemd service units;
- services exposing multiple matching runtime sources.

## Official packs

This release is designed for the expanded official pack registry, including additional infrastructure, database and proxy coverage.

Official packs declare compatibility with the Server, Agent and Pack Engine before they are activated.
