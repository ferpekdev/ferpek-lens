# Troubleshooting

FERPEK Lens is still under active development.

This section will collect common installation, enrollment, agent, pack and connectivity problems.

## Useful checks

When diagnosing a problem, verify:

- the FERPEK Lens containers are running;
- the server health endpoint responds;
- the FERPEK Agent service is active;
- the host can reach the FERPEK Lens server;
- the agent has valid credentials;
- the expected pack is enabled for the host.

More detailed troubleshooting procedures will be added as the project matures.
