# Pack development

FERPEK Lens packs are intended to be portable and largely declarative.

A pack defines how a service is discovered, which sources contain its logs and how those logs should be interpreted.

Pack development documentation is still being expanded.

Future documentation will cover:

- pack directory structure;
- manifest format;
- supported platforms;
- service discovery;
- source definitions;
- rule definitions;
- findings;
- relevant activity;
- pack validation;
- testing;
- publishing packs.
