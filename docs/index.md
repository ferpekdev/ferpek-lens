# FERPEK Lens

**Open-source log analysis for system administrators.**

FERPEK Lens helps turn infrastructure logs into relevant activity and actionable findings.

A lightweight agent runs on monitored hosts, discovers available log sources and uses packs to interpret service-specific events.

The FERPEK Lens server provides a central interface for managing hosts, packs, activity, findings and configuration.

## Start here

If this is your first time using FERPEK Lens, begin with the installation guide and then add your first host.

FERPEK Lens is currently under active development and should not yet be considered production-ready.
